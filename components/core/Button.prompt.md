One-line: the primary commerce action — use `primary` for "AGREGAR AL CARRITO" / "COMPRAR AHORA", `secondary` for alternates, `sale` only for discount-driven CTAs.

```jsx
<Button size="lg" iconRight="arrow-right">Comprar ahora</Button>
<Button variant="secondary">Vista rápida</Button>
```

Labels are always uppercase in Spanish (the component uppercases for you). Never round the corners.
