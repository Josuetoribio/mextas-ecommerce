One-line: thin-stroke Lucide glyph used for every icon in MEXTAS UI — never emoji, never hand-drawn SVG.

```jsx
<Icon name="shopping-bag" size={22} />
```

Requires the Lucide UMD script on the page: `<script src="https://unpkg.com/lucide@latest/dist/umd/lucide.js"></script>`.
Sizes in use: 16 (inline/meta), 20 (header, buttons), 22–24 (nav actions), 28+ (benefit strip).
